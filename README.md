# WeaveLink

Authenticated direct-market platform for rural handloom weavers.

**Handloom Hackathon 2026 · Theme 2 — Market Access & Digital Integration**

## Current status

Frontend showcase demo only (mocked catalog, authenticity, orders). Backend / DB after selection.

## Run locally

```bash
cd WeaveLink
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Demo routes for your pitch video

1. `/` — Landing thesis (WeaveLink brand + DPP hero)
2. `/sell` — Voice / photo listing → AI draft → passport
3. `/verify/WL-KAN-2026-08421` — Public authenticity scan
4. `/product/p-kanchi-maroon` — B2C product + weaver story
5. `/b2b` — Bulk RFQ desk
6. `/dashboard` — Seller orders & inventory
7. `/marketplace` — Filtered authenticated browse
